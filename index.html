GOED OM TE WETEN

Veelgestelde vragen.

Alles wat je nodig hebt om je avontuur te beginnen.

Hoe kan ik meespelen? +

Open Minecraft Java Edition, voeg het serveradres toe bij Multiplayer en maak verbinding. Het definitieve adres wordt hier nog ingevuld.

Welke Minecraft-versie heb ik nodig? +

De ondersteunde Minecraft-versie wordt bekendgemaakt zodra de servergegevens zijn ingesteld.

Kan ik samen met vrienden spelen? +

Natuurlijk is samen ontdekken extra leuk. Deel straks het serveradres met je vrienden en spreek af in de wereld.
