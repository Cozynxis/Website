# Evermore — Minecraft website

Een responsive, Nederlandstalige Minecraft-communitywebsite met een sprookjesachtige bosstijl, geïnspireerd door de sfeer van Nederlandse Minecraft-attractieparken.

## Bestanden
- `index.html` — pagina-inhoud en secties
- `style.css` — vormgeving, animaties en mobiele layout
- `script.js` — mobiel menu, jaartal en kopieerknop voor het serveradres

## Zelf aanpassen
1. Pas de naam **Evermore** in `index.html` aan als je een andere servernaam wilt.
2. Vervang `play.jouwserver.nl` door het echte Minecraft-serveradres.
3. Vervang de voorbeeldafbeeldingen door screenshots van je eigen server.
4. Vul de juiste Minecraft-versie, Discord-link en echte nieuwsberichten in voordat je publiceert.

De huidige servernaam, nieuwsberichten en serverinformatie zijn bewust als placeholders ingericht; er worden geen echte spelersaantallen of live serverstatus verzonnen.

## Publiceren via GitHub Pages
1. Open **Settings → Pages** in deze repository.
2. Kies **Deploy from a branch**.
3. Selecteer branch `main` en map `/ (root)), en klik op **Save**.
4. Wacht tot GitHub Pages de site heeft gepubliceerd.

De website gebruikt gewone HTML, CSS en JavaScript en heeft geen buildstap nodig.
